Розподілена система динамічної маршрутизації екстрених служб у районах із пошкодженою інфраструктурою

Кваліфікаційна (дипломна) робота здобувача освіти (Рівненський фаховий коледж інформаційних технологій).

 Мета проєкту
Розробка програмної системи для оперативного прокладання та динамічного перерахунку оптимальних маршрутів руху екіпажів екстрених служб (ДСНС, швидка медична допомога, поліція) в умовах зруйнованої дорожньої мережі, завалів або перекриття ділянок доріг.

Основний функціонал
- Інтерактивна карта інфраструктури: відображення дорожньої мережі (OpenStreetMap), інцидентів та статусу проїзності ділянок.
- Управління пошкодженнями:додавання та оновлення зон блокування доріг або обмежень проїзду диспетчером чи екіпажами.
- Динамічний перерахунок маршрутів:автоматична перебудова маршруту на графі доріг (алгоритми A* / Дейкстри з урахуванням вагових коефіцієнтів проїзності) при появі нових перешкод.
- Розподілена взаємодія:** синхронізація стану дорожньої мережі між сервісом маршрутизації, панеллю диспетчера та клієнтами екіпажів у реальному часі.

 Стек технологій
- Мови програмування:Python, TypeScript
- Backend: FastAPI, NetworkX / OSMnx (обробка графів дорожньої мережі)
- Frontend: React, Leaflet (візуалізація карт і маршрутів)
- База даних:PostgreSQL + PostGIS (збереження геопросторових даних)
- Брокер повідомлень та інфраструктура:Redis (Pub/Sub), Docker
