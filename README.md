Розподілена система динамічної маршрутизації екстрених служб у районах із пошкодженою інфраструктурою
Керівник: Теа Максим 
Стек технологій

Мови програмування:Python, TypeScript
Фреймворки та бібліотеки:
Backend:FastAPI, NetworkX / OSMnx (побудова графів дорожньої мережі та розрахунок маршрутів)
Frontend:React, Leaflet (інтерактивна карта, візуалізація маршрутів і перешкод)
База даних:PostgreSQL із розширенням PostGIS (збереження та індексація геопросторових даних)
Брокер повідомлень та розгортання:Redis (Pub/Sub для синхронізації змін у реальному часі), Docker

 Мета проєкту
Розробка програмної системи для оперативного прокладання та динамічного перерахунку оптимальних маршрутів руху екіпажів екстрених служб (ДСНС, швидка медична допомога, поліція) в умовах зруйнованої дорожньої мережі, завалів, затоплень або перекриття ділянок доріг.

Основний функціонал
- Інтерактивна карта інфраструктури:відображення дорожньої мережі (на основі OpenStreetMap), поточних інцидентів та статусу проїзності ділянок.
- Управління пошкодженнями:оперативне додавання та оновлення зон блокування доріг або обмежень проїзду диспетчером чи екіпажами.
- Динамічний перерахунок маршрутів: автоматична перебудова маршруту на графі доріг (алгоритми A* / Дейкстри з урахуванням вагових коефіцієнтів проїзності) при появі нових перешкод на шляху екіпажу.
- Розподілена взаємодія: миттєва синхронізація стану дорожньої мережі між сервісом маршрутизації, панеллю диспетчера та терміналами екіпажів.
